# Адаптивное выравнивание главного экрана

## Цель

Сделать композицию главного экрана естественной для каждого формата: на телефонах собрать текст и действия по центру, а на компьютерах выровнять всю текстовую колонку по левому краю.

## Поведение

### Мобильные и планшетные экраны до 64rem

- Eyebrow, заголовок, описание и строка лицензии центрируются внутри текстовой колонки.
- Описание сохраняет ограничение читаемой длины и получает автоматические боковые отступы.
- Группа кнопок остаётся по центру: основная кнопка сверху, вторичная ниже.
- Строка лицензии сохраняет иконку и текст, но вся группа центрируется; сам текст читается по левому краю внутри строки, чтобы длинный номер лицензии не выглядел рваным.

### Компьютеры от 64rem / 1024px

- При включении существующего двухколоночного hero текстовая колонка целиком выравнивается по левому краю.
- Eyebrow, заголовок, описание, обе кнопки и строка лицензии имеют общий левый край.
- Группа кнопок сохраняет утверждённую вертикальную иерархию и текущую максимальную ширину.
- Изображение остаётся в правой колонке без изменения размеров и кадрирования.

## Технические границы

- Изменяется только `src/styles/pages.css` и целевой CSS-тест.
- HTML, данные клиники, текст лицензии, ссылки, JavaScript и остальные CTA не меняются.
- Используется существующий breakpoint `@media (min-width: 64rem)` и текущие семантические токены.
- Не добавляются новые цвета, размеры, зависимости или анимации.

## Доступность и проверка

- Порядок чтения DOM и клавиатурная навигация не меняются.
- Зоны нажатия и `:focus-visible` существующих кнопок сохраняются.
- На 320px и 390px проверяется центрирование и отсутствие горизонтального overflow.
- На 1024px и 1280px проверяется единый левый край текстовой колонки и сохранение правой медиаколонки.
- Полный `pnpm verify` должен подтвердить тесты, production build и 21 HTML-страницу.
