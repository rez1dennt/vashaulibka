# Выравнивание главного экрана по левому краю

## Цель

Сохранить весь контент главного hero по левому краю на всех ширинах.

## Поведение

- Группа кнопок выровнена по левому краю на мобильных и компьютерах.
- Заголовок, eyebrow, описание и строка лицензии также остаются слева.
- Размеры, порядок, тексты, ссылки и зоны нажатия кнопок не меняются.
- Изображение и двухколоночная desktop-композиция не меняются.

## Технические границы и проверка

- Изменяются только `src/styles/pages.css` и целевой CSS-тест.
- Для выравнивания кнопок не используется отдельный breakpoint: правило едино для всех ширин.
- На 320px, 390px, 1024px и 1280px проверяется левый край кнопок.
- Отдельно проверяется, что для `.home-hero__copy`, `.home-hero__lead` и `.home-hero__trust` не добавлены правила адаптивного выравнивания.
- Полный `pnpm verify` должен пройти без ошибок.
