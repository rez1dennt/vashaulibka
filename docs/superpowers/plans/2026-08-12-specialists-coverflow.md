# Specialists Coverflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the plain specialists list with a responsive, cyclic three-card coverflow and a synchronized verified-details panel without fabricating staff information.

**Architecture:** Keep `src/data/staff.js` as the single source of truth, move specialists markup into a focused content module, and progressively enhance its complete static list with a dependency-free controller. CSS reads explicit `data-position` states and reverts to a normal grid under `.no-js`, while the existing appointment dialog remains the only booking integration.

**Tech Stack:** Static ES modules, semantic HTML generated by Node, vanilla JavaScript, tokenized CSS, Vitest, JSDOM, Vite.

## Global Constraints

- Render only the five confirmed records from `STAFF`; do not invent photographs, education, accreditation, experience, certificates, specializations, or clinical claims.
- Keep `specialists.html` as `noindex, follow` until the clinic supplies complete verified staff information.
- Do not add GSAP, carousel packages, external fonts, trackers, forms, or new runtime dependencies.
- Do not auto-advance the coverflow.
- Preserve a complete readable five-person list when JavaScript is unavailable.
- Use the existing `[data-appointment-open]` telephone dialog for booking.
- Respect `prefers-reduced-motion: reduce`, keyboard navigation, focus visibility, and a minimum 44×44 px control target.
- Use only the project token layers for new dimensions, colors, shadows, transitions, and transforms.

Create `src/js/components/specialists-coverflow.js`:

```js
const positionFor = (index, activeIndex, length) => {
  const forward = (index - activeIndex + length) % length;
  if (forward === 0) return 'active';
  if (forward === 1) return 'next';
  if (forward === length - 1) return 'previous';
  return forward <= Math.floor(length / 2) ? 'far-next' : 'far-previous';
};

export function initSpecialistsCoverflow() {
  document.querySelectorAll('[data-specialists-coverflow]').forEach((root) => {
    const slides = [...root.querySelectorAll('[data-specialist-slide]')];
    const viewport = root.querySelector('[data-specialist-viewport]');
    const counter = root.querySelector('[data-specialist-counter]');
    const detailName = root.querySelector('[data-specialist-detail-name]');
    const detailRole = root.querySelector('[data-specialist-detail-role]');
    if (!slides.length || !viewport) return;

    let activeIndex = 0;
    let pointerStart = null;
    const activate = (index) => {
      activeIndex = (index + slides.length) % slides.length;
      slides.forEach((slide, slideIndex) => {
        const position = positionFor(slideIndex, activeIndex, slides.length);
        slide.dataset.position = position;
        if (slideIndex === activeIndex) slide.setAttribute('aria-current', 'true');
        else slide.removeAttribute('aria-current');
        const select = slide.querySelector('[data-specialist-select]');
        if (select) select.tabIndex = ['active', 'previous', 'next'].includes(position) ? 0 : -1;
      });
      const active = slides[activeIndex];
      if (counter) counter.textContent = `${activeIndex + 1} / ${slides.length}`;
      if (detailName) detailName.textContent = active.querySelector('.specialist-card__name')?.textContent.trim() || '';
      if (detailRole) detailRole.textContent = active.querySelector('.specialist-card__role')?.textContent.trim() || '';
    };

    root.querySelector('[data-specialist-prev]')?.addEventListener('click', () => activate(activeIndex - 1));
    root.querySelector('[data-specialist-next]')?.addEventListener('click', () => activate(activeIndex + 1));
    slides.forEach((slide, index) => slide.querySelector('[data-specialist-select]')
      ?.addEventListener('click', () => activate(index)));

    viewport.addEventListener('keydown', (event) => {
      if (!['ArrowLeft', 'ArrowRight', 'Home', 'End'].includes(event.key)) return;
      event.preventDefault();
      const target = event.key === 'Home' ? 0
        : event.key === 'End' ? slides.length - 1
          : activeIndex + (event.key === 'ArrowRight' ? 1 : -1);
      activate(target);
    });
    viewport.addEventListener('pointerdown', (event) => { pointerStart = event.clientX; });
    viewport.addEventListener('pointerup', (event) => {
      if (pointerStart === null) return;
      const distance = event.clientX - pointerStart;
      pointerStart = null;
      if (Math.abs(distance) >= 48) activate(activeIndex + (distance < 0 ? 1 : -1));
    });
    viewport.addEventListener('pointercancel', () => { pointerStart = null; });

    root.classList.add('is-enhanced');
    activate(0);
  });
}
```
