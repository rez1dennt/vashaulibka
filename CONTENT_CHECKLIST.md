# Что необходимо получить до публичного релиза без ограничений

- [ ] Утверждённый клиникой прейскурант с полными наименованиями и ценами услуг.
- [ ] Подтверждённые сведения об образовании каждого медицинского работника.
- [ ] Подтверждённые сведения об аккредитации или сертификате каждого медицинского работника.
- [ ] Подтверждённый стаж работы по специальности каждого медицинского работника.
- [ ] Подтверждённые отзывы, если клиника решит их публиковать.
- [ ] Актуальные вакансии, если клиника решит их публиковать.
- [ ] Реальный production-домен для абсолютных URL в `sitemap.xml`, canonical URL и полного адреса сайта в политике конфиденциальности.
- [ ] Выбранный поставщик хостинга, страна и регион размещения серверов, договорные роли сторон и контакт для обращений по инфраструктуре.
- [ ] Фактический состав серверных журналов: фиксируются ли IP-адрес, дата и время, запрошенный URL и сведения о браузере; цели, срок хранения, круг имеющих доступ лиц и порядок удаления.
- [ ] Документация и параметры подключения МИС, включая точки интеграции, авторизацию и схему ошибок.
- [ ] Правовая и техническая проверка будущего потока персональных данных через МИС: состав данных, цели, основания, операторы, хранение, трансграничная передача и согласия.
- [ ] Финальное письменное одобрение клиникой публикуемых контактов, режима работы, сведений о лицензии и всех правовых текстов.
- [ ] Финальная проверка сайта квалифицированным российским юристом непосредственно перед production-публикацией и после существенных изменений законодательства.
- [ ] Фактические фотографии клиники и подтверждение прав на их публикацию, если иллюстративные hero-изображения будут заменены.

## Контролируемая публикация

До получения и проверки обязательных данных страницы цен и специалистов остаются с `noindex` и не включаются в наполненный `sitemap.xml`:

- `prices.html` можно открыть для индексации после публикации утверждённого прейскуранта;
- `specialists.html` можно открыть для индексации после добавления подтверждённых образования, аккредитации/сертификата и стажа по специальности для каждого медицинского работника.

После обновления контента и SEO-статуса нужно обязательно выполнить `pnpm generate`, затем `pnpm verify`.
